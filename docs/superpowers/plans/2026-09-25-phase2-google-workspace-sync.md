# Phase 2 Google Workspace Directory Sync — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Đồng bộ nhân sự Google Workspace Directory vào API (BullMQ + Redis, SA/OAuth, incremental sync, bulk upsert) theo MVC hiện tại, tối ưu cho org lớn.

**Architecture:** Worker BullMQ gọi `GoogleDirectoryClient` (SA ưu tiên, fallback OAuth admin). `WorkspaceSyncService` paginate Directory → bulk upsert `google_workspace_sync` + link/create `users`. HTTP chỉ enqueue/đọc status qua Controller. Không auto-mutate `team_members`.

**Tech Stack:** Express, Prisma/PostgreSQL, BullMQ, ioredis, `googleapis` (Admin SDK), Zod, Vitest. Giữ AES encrypt từ Phase 1 cho OAuth tokens.

**Spec:** `docs/superpowers/specs/2026-09-25-phase2-google-workspace-sync-design.md`

```ts
  globalForRedis.redis ??
  new Redis(env.REDIS_URL, { maxRetriesPerRequest: null });

if (process.env.NODE_ENV !== "production") {
  globalForRedis.redis = redis;
}

export async function acquireLock(
  key: string,
  ttlSeconds: number,
): Promise<boolean> {
  const result = await redis.set(key, "1", "EX", ttlSeconds, "NX");
  return result === "OK";
}

export async function releaseLock(key: string): Promise<void> {
  await redis.del(key);
}

export async function isLocked(key: string): Promise<boolean> {
  return (await redis.exists(key)) === 1;
}
```

- [ ] **Step 3: Implement hash**

```ts
// src/lib/content-hash.ts
import { createHash } from "node:crypto";

export type WorkspaceUserHashInput = {
  primaryEmail: string;
  fullName: string;
  orgUnit: string | null;
  photoUrl: string | null;
  suspended: boolean;
};

export function workspaceUserContentHash(input: WorkspaceUserHashInput): string {
  const payload = [
    input.primaryEmail.toLowerCase(),
    input.fullName,
    input.orgUnit ?? "",
    input.photoUrl ?? "",
    input.suspended ? "1" : "0",
  ].join("|");
  return createHash("sha256").update(payload).digest("hex").slice(0, 32);
}
```

- [ ] **Step 2: `runSync(orgId, triggeredByUserId?)`**

Pseudocode to implement fully:

```
lock = acquireLock(`lock:sync:google-workspace:${orgId}`, 600)
if !lock: return { skipped: true }
log = syncLogs.createRunning(...)
try:
  client = await auth.resolveClientForOrg(orgId)
  settings = await settingsRepo.getOrCreate(orgId)
  mode = settings.directorySyncToken ? 'incremental' : 'full'
  pageToken = settings.syncCursorPageToken
  syncToken = settings.directorySyncToken
  counters = zeros
  loop:
    page = await client.listUsersPage({ syncToken, pageToken, maxResults: 200 })
    counters.apiCalls++
    processPage(orgId, page.users, counters)  // bulk upsert + link
    pageToken = page.nextPageToken
    await settingsRepo.update cursor
    if page.newSyncToken: syncToken = page.newSyncToken
    if !pageToken: break
  save token + last_* timestamps
  finish log success + meta
catch SyncTokenInvalid:
  clear token; retry once as full
catch err:
  finish log failed/partial
finally:
  releaseLock
```

### Task 7: Worker

**Files:**

- [ ] **Step 1: Worker**

```ts
import { Worker } from "bullmq";
import { env } from "../lib/env.js";
import { WORKSPACE_SYNC_QUEUE } from "../lib/queue.js";
import type { WorkspaceSyncService } from "../services/workspace-sync.service.js";

export function startWorkspaceSyncWorker(syncService: WorkspaceSyncService) {
  const worker = new Worker(
    WORKSPACE_SYNC_QUEUE,
    async (job) => {
      const { orgId, triggeredByUserId } = job.data as {
        orgId: string;
        triggeredByUserId?: string;
      };
      return syncService.runSync(orgId, triggeredByUserId);
    },
    {
      connection: { url: env.REDIS_URL },
      concurrency: 2,
      limiter: { max: 10, duration: 60_000 },
    },
  );
  worker.on("failed", (job, err) => {
    console.error("workspace sync failed", job?.id, err);
  });
  return worker;
}
```
