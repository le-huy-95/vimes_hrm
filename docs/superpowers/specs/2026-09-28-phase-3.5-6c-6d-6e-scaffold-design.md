# Design: Scaffold Phase 3.5 / 6c / 6d / 6e

**Date:** 2026-09-28  
**Status:** Approved (chat option A)  
**Parent:** [v2.5](./2026-09-28-ke-hoach-trien-khai-v2.5-design.md)

## In scope

### 3.5 Bridge Chat stub
- Tables: `google_chat_spaces`, `google_message_map`, `chat_watch_state`
- `POST /internal/google-chat/ingest` — upsert message vào chat-service với `origin=GOOGLE_CHAT` (via internal or direct DB if message origin column)
- Watch-manager stub: renew timer log; status ACTIVE/DEGRADED
- No real Pub/Sub

### 6c Semantic search stub
- Table `content_embeddings` (vector as JSON float[] fallback if no pgvector)
- Indexer stub endpoint + FTS hybrid search tool in ai-service
- Permission filter by group membership

### 6d Admin AI tools
- `GET /ai/admin/ops` — health snapshot, sync_jobs backlog, dlq stub counts
- Guard: `PLATFORM_ADMIN_USER_IDS` env allowlist

### 6e Proactive / bot stub
- Worker cron stub endpoint for overdue digest email
- Google Chat `@bot` action routes to ai-service chat stub

## Out of scope
- 6b pending_action
- Real Pub/Sub, real embeddings API, production Google Chat JWT
