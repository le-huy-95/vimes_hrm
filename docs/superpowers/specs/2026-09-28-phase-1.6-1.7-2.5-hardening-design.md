# Design: Hoàn thiện Phase 1.6 / 1.7 / 2.5 (backend scaffold → usable)

**Date:** 2026-09-28  
**Status:** Approved (chat)  
**Parent:** [v2.5 design](./2026-09-28-ke-hoach-trien-khai-v2.5-design.md)

## Goal

Nâng scaffold chat file / reaction-search / Google Tasks pull lên mức **dùng được nội bộ**, không claim đủ checklist 2 tuần từng phase.

## In scope

### 1.6 File
- Group quota (`GROUP_FILE_QUOTA_BYTES`, empty/null = unlimited)
- Clear `orphan_after` khi file READY
- List messages trả `fileIds` / attachment metadata tối giản

### 1.7 Reaction / search / mention
- Reactions summary khi list messages
- Search optional `groupId` / `taskId` (verify membership via conversation)
- Giữ mention socket + FTS unaccent (đã có)

### 2.5 Pull
- Không enqueue TASKS_PUSH khi `completedSource=google`
- Pull log `changedFields`; giữ cooldown / DETACHED / marker

## Out of scope

- Multipart resume, ClamAV thật, thumbnail, CDN
- FCM/APNs, email digest
- Merge 3 chiều title/due/notes đầy đủ
- Phase 3 / 4 / 6a

## Acceptance (vòng này)

1. Upload → complete → post message với `fileIds` → member download  
2. Reaction realtime; FTS unaccent  
3. Complete từ Google không tạo vòng push
