# Phase 1–3 Flutter API + UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Thay Home debug bằng App Shell responsive + ghép API Phase 1–3 (Org/Group/Task Kanban+Lịch/Chat/Sync) theo spec, dùng BLoC only và theme Vimes.

**Architecture:** `AppShell` (bottom tabs mobile / top nav web) + `WorkspaceBloc` (org/group context) + feature BLoCs (`HomeBloc`, `TasksBloc`, `ChatListBloc`, `ChatThreadBloc`, `SyncBloc`). Repositories mở rộng typed models; REST gateway `:3200`, Socket `:3204`.

**Tech Stack:** Flutter 3.8+, flutter_bloc, go_router, dio, socket_io_client, table_calendar, shared_preferences, ColorSkin/BeVietnamPro.

**Spec:** `frontend/docs/superpowers/specs/2026-09-28-phase1-3-api-ui-design.md`
