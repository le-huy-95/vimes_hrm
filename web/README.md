# Manage Teams Web (Phase 1)

> Intended as sibling repo `manage-teams-web`. Currently nested under API as `web/` for scaffolding; move with:
> `mv web ../manage-teams-web`

## Run

```bash
cp .env.example .env
npm install
npm run dev
```

Requires API at `VITE_API_URL` (default `http://localhost:3001`).
