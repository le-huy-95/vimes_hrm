Phạm vi sửa UI board?

Màu vẫn dùng ColorSkin hệ thống — chỉ hỏi layout nào cần đổi. Click để chọn.

A

Chỉ thẻ task

Đổi layout card: badge ID + icon trạng thái · title · avatar/tên · ngày · comment. Giữ nguyên header cột, empty state, nút tạo task hiện tại.

B

Thẻ + cột (khuyến nghị)

Đổi card như ảnh, thêm header cột (tên · count · ⋯), empty drop zone dashed khi cột trống. Giữ tab Board/List/Lịch và nút tạo task như hiện tại.

C

Toàn bộ board như ảnh

Card + cột + style tab underline + FAB (+) góc phải. Đổi nhiều hơn, chạm cả chrome ngoài card.
