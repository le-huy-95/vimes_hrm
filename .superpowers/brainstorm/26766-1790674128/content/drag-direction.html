Kéo thả đổi trạng thái theo hướng nào?

Hiện API chỉ có claim (→ đang làm) và complete (→ DONE). Chưa có “mở lại” task đã xong.

1 — Chỉ kéo sang Hoàn thành

Kéo từ Cần làm → Hoàn thành = complete. Không kéo ngược. Ít thay đổi backend, ship nhanh.

2 — Kéo 2 chiều

Kéo sang Hoàn thành = complete; kéo về Cần làm = reopen (cần thêm API backend).
