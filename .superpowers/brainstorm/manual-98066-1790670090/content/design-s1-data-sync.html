Design §1 — Data & sync

Hạn chót date-only trên task nhóm · gán/claim kích hoạt Google push

Schema
tasks.due_date  DATE NULL   -- chỉ ngày, timezone local user khi hiển thị
-- không thêm starts_at / ends_at đợt này
-- task_assignees giữ nguyên (multi)
Google sync
  • Push: thêm due (RFC3339 midnight UTC date) vào payload cùng title/notes/status
  • Pull: merge due → tasks.due_date (local thắng nếu updatedAt mới hơn)
  • Khi nào có bản Google: chỉ khi user là ACTIVE assignee (claim hoặc được gán) — pool task chưa có link
  • Gỡ assignee / REMOVED → có thể detach link (out of scope tối thiểu: giữ link, không push tiếp)
API mới / mở rộng
  • PATCH /groups/:id/tasks/:code — { title?, description?, dueDate?: "YYYY-MM-DD" | null }
  • Create/list/get đã có assignee — create mặc định assigneeIds: []
  • Giữ POST .../claim, POST .../assign — assign xong enqueue TASKS_PUSH cho target
